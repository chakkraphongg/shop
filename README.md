## 🎮 2. ลูกเล่น 3D Hologram Stage (หมุนตัวละคร 3D)

- **หมุนตัวละคร 360°:** คลิกเมาส์ค้างแล้วลาก (หรือใช้นิ้วปัดบนจอมือถือ) ตัวละครจะหมุนตามแกน 3D Perspective อย่างสมจริง
- **โหมดหมุนอัตโนมัติ:** กดปุ่ม **"🔄 หมุนอัตโนมัติ"** เพื่อให้โมเดลหมุนวน 360° ตลอดเวลา หรือกดหยุดหมุน / รีเซ็ตมุมมองได้
- **ส่อง 3D จากหน้ารวมสินค้า:** บนการ์ดฮีโร่ทุกใบจะมีปุ่ม **"🔄 หมุน 3D"** เมื่อกดแล้วจะเปิดหน้าต่าง Quick Inspect 3D Modal ขึ้นมาเพื่อดูรายละเอียดและสั่งซื้อได้ทันที
- **3D Card Hover Tilt:** เลื่อนเมาส์ผ่านการ์ดสินค้าในหน้าแรกและหน้ารวม จะมีเอฟเฟกต์การ์ดเอียง 3D ตามตำแหน่งเมาส์

## 🚀 4. วิธีนำขึ้น GitHub Pages (Deployment)

1. สร้าง Repository ใหม่บน GitHub เช่น `hero-store`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปยัง Repository
3. ไปที่แท็บ **Settings** > **Pages** ของ Repository
4. ในส่วน **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** หรือ **master** และโฟลเดอร์ **/ (root)**
   - คลิก **Save**
5. รอระบบ GitHub ทำการ Deploy ประมาณ 1 - 2 นาที จะได้ลิงก์เว็บไซต์ออนไลน์ เช่น `https://<username>.github.io/hero-store/` พร้อมเปิดให้ทุกคนเข้าดูได้ทันทีตลอด 24 ชั่วโมง โดยไม่ต้องเปิดคอมพิวเตอร์ทิ้งไว้!
